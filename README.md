# MoonlightC

Every AI in one place: cloud models, local models, creative tools and your own computers.
Free and open source (MIT). Bring your own keys.

## Develop
```bash
pnpm install
pnpm dev        # web app on http://localhost:3000
pnpm build && pnpm --filter @moonc/web e2e
```
See `docs/SPEC.md` for the product and `docs/PROGRESS.md` for status.
