# MoonlightC product research (Nov 2026)

Method: 21 web searches plus 2 page fetches (OpenAI community forum, Hacker News, Claude Code issue trackers, TypingMind/Msty
feedback, vendor and review blogs). Many sources are forum posts and blogs, so evidence is anecdotal, not measured. Evidence is
paraphrased. Size: S = hours, M = a day, L = days. "Paid" = needs a paid service beyond the user's own API keys.

Ranking = value to a non-technical user x feasibility for a small web + Electron app with bring-your-own keys.

## Recommended build order (value / effort)
1. Quick wins (S): 11 export/import, 14 memory page, 17 connector Test button, 19 prompt library.
2. Trust and safety (the product's edge, because it has a browser extension): 1 proof-of-work receipts, 5 untrusted-page rules and
   clean-profile mode, 6 takeover/resume, 13 checkpoints and undo.
3. Daily chat quality: 2 context meter and summarize-continue, 3 cost and budgets, 4 full-text search, 10 branching, 20 auto model and fallback.
4. Studio: 7 inpainting, 8 compare-on-N-models, then 9 brand/character kit.
5. Bigger bets: 12 "Fix it" and deploy for non-coders, 15 local model installer, 18 remote status and wake, 16 voice.

## Cross-cutting themes
- Trust beats speed: users forgive slow agents, not agents that lie, act on hidden instructions, or do something irreversible.
- Invisible state is the top annoyance: context used, money spent, quota left, which model answered, what memory was used.
- Nothing should be lost: every edit, branch, image version and agent change should be restorable and exportable.
- Browser agents are not a settled category; reliability is poor on login/captcha pages, so a clean handoff to the human is a feature, not a failure.
- Multi-provider is the differentiator for MoonlightC: compare, fall back, and price-check across providers, which single-vendor apps will not do.

## Notes and confidence
- Evidence is mostly forum posts, issue trackers and blogs; some vendor blogs are promotional. Counts or percentages quoted in sources were not repeated here.
- Not covered well: Reddit threads (the search tool returned none), Gemini-specific complaints, Cherry Studio and Msty request lists.
- A source claimed one browser product was being retired in Aug 2026; unverified and not used.
